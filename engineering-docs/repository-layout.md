# Repository Layout

The FlowStrix project is organized into three major layers: the core Python package (`src/flowstrix/`), the React web workspace (`ui/`), and user configuration files / examples (`examples/`).

## 🔑 Crucial Source Code Entrypoints

### 1. The Gateway Factory (`gateway.py`)
This file intercepts all LLM connection requests. It determines whether a `GEMINI_API_KEY` or `GROQ_API_KEY` is present, chooses the appropriate endpoint (Google's AI Studio or Groq), sets up the base client parameters, and resolves short aliases to official provider model identifiers.

### 2. LangGraph Executor (`engine/executor_v2.py`)
The modern execution engine. It compiles the linear and branched steps defined in your YAML specification into an active LangGraph state machine. It handles thread checkpointers for session persistence, enabling multi-turn conversation states.

### 3. Ghostwriter Compiler (`compiler/ghostwriter.py`)
Responsible for compiling natural language descriptions into valid YAML specifications. It uses **Instructor** to force the LLM to output tokens that match the exact shape of our Pydantic `AgentSpec` model. It retries generation automatically if the generated schema violates YAML validity.

### 4. Vector store (`knowledge/vectorstore.py`)
Uses the lightweight **FastEmbed** library (`BAAI/bge-small-en-v1.5`) to create text embeddings locally. Ingested knowledge chunks are stored inside a localized Qdrant database to perform semantic RAG lookups during reasoning steps.
